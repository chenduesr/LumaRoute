# MyRay Lite 0.2.2

## 新功能

- 新增可持久化的简洁模式，完整模式的原布局和全部功能保持不变。
- 简洁模式提供节点选择、连接/断开、全部订阅更新、主题切换和返回完整模式。
- 订阅页增加“全部更新”，依次处理所有订阅；单项失败不会中断其他订阅，旧节点继续保留。
- 设置中增加“启动时更新订阅”，默认开启。若同时启用自动连接，会先完成订阅更新再连接。
- 新安装默认使用 `chenduesr/MyRay-Lite-Tauri` 作为应用更新源。

## 兼容性

- 原有外观设置缺少简洁模式字段时按完整模式处理，不会清除已保存的主题、紧凑布局或动态效果设置。
- 旧的代理设置缺少启动更新字段时使用默认值；节点、订阅和其他设置的数据结构保持兼容。
- 简洁模式使用同一套 Rust 服务和本地数据，不创建重复配置。

## 验证边界

- 自动订阅测试使用本机 HTTP 服务与隔离数据目录，不访问真实订阅，也不修改 Windows 系统代理。
- 真实节点、系统代理切换、安装升级和 Windows 10 独立机器测试仍需另行验证。

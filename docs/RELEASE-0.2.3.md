# MyRay Lite 0.2.3

## 简洁模式增强

- 在简洁模式中直接添加订阅。保存后立即更新该订阅，失败时保留订阅记录并显示原因。
- 第一次成功获取节点且当前没有选择时，自动选择该订阅的第一个节点。
- 节点选择框显示协议和最近延迟，并将成功测速的低延迟节点排在前面。
- 主测速按钮使用 HTTP 延迟检查当前节点；下拉菜单提供当前/全部节点的 HTTP 与 TCP 延迟测试。
- 测速沿用后台并发、重试、进度和取消机制，不会切换 Windows 系统代理。

## 界面尺寸

- 默认窗口由 1200×800 调整为 1280×860，最小窗口由 820×620 调整为 900×660。
- 简洁模式内容区由 560px 放大至 680px，同时放大连接卡片、电源按钮、节点选择框和底部操作按钮。
- 完整模式的页面结构、导航和功能保持不变。

## 验证

- TypeScript 检查与 Vite 生产构建通过。
- 简洁模式 UI 自动化通过：订阅保存/立即更新、当前节点 HTTP 测试、全部节点 TCP 测试、900×660 无横向溢出。
- Tauri 开发版和 Release 主程序的原生端到端测试均通过，不修改系统代理。
- Rust 12 项测试通过，包括真实 Xray/sing-box 隔离 HTTP、下载测速与订阅失败数据保护。
- NSIS EXE 与 WiX MSI 构建成功；MSI 0.2.3 中包含主程序、双核心、DLL 与路由数据。

真实订阅、真实远端节点、Windows 系统代理切换、安装升级和 Windows 10 独立机器测试未在本轮执行。

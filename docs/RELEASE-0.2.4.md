# MyRay Lite 0.2.4

## Windows 凭据保护

- `profile.json` 使用 Windows DPAPI 加密后写入磁盘，密钥绑定当前 Windows 用户。
- 订阅 URL、节点密码、UUID、分享链接、证书指纹和应用设置均不再以可读 JSON 保存。
- 现有 0.2.3 及更早版本的明文配置仍可读取；下一次保存时自动转换为 DPAPI 密文。
- `profile.backup.json` 使用同样的加密格式，恢复备份流程保持可用。
- 写入仍采用临时文件、磁盘同步和原子替换；损坏配置继续保留，避免覆盖。

## 验证

- DPAPI 加密/解密、加密备份、损坏文件保护测试通过。
- 原生测试从旧版明文配置启动，保存设置后确认文件已转换为 `MYRAY-DPAPI-1` 密文格式。
- 配置密文中不包含测试订阅令牌。

DPAPI 密文只能由创建它的 Windows 用户在同一系统凭据环境中解密。跨用户或跨电脑迁移应通过后续提供的加密导出功能完成。

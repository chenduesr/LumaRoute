# MyRay Lite 0.2.5

这一版补齐快捷订阅、托盘常用操作和窗口状态记忆，并包含未单独发布的 0.2.4 Windows 凭据保护。自动选择最佳节点、收藏和节点分组不在本版本范围内。

## 快捷订阅

- 在简洁模式或完整模式打开“添加订阅”时读取一次 Windows 剪贴板，识别其中第一个 HTTP/HTTPS 链接。
- 按链接域名生成默认订阅名称，并在保存前显示域名预览；用户修改过的名称不会被自动覆盖。
- 支持选择 PNG、JPEG、WebP 或 BMP 二维码图片，在本机解码订阅链接。
- “保存并更新”一次完成建档和节点获取。
- 新建或编辑订阅与其他已有地址重复时保留对话框，并提示直接更新已有订阅。
- 剪贴板使用 Tauri 官方插件的只读权限。应用只在快捷添加对话框打开或用户点击“读取剪贴板”时读取，不持续监听剪贴板。

## 托盘快捷操作

- 显示当前连接状态对应的“连接”或“断开连接”。
- 显示当前节点和最近使用的三个仍然存在的节点。
- 支持更新全部订阅、以 HTTP 方式测试当前节点、切换简洁模式和打开主窗口。
- 每秒刷新实时上传/下载速度；无节点、正在运行任务或已连接等状态下自动禁用不适用的菜单项。
- 最近节点只记录手动选择历史。订阅更新删除旧节点后会同步清理失效记录。

## 窗口记忆

- 完整模式和简洁模式分别保存窗口位置、客户区尺寸和最大化状态。
- 切换模式时恢复对应尺寸；下次启动恢复上次使用模式的窗口状态。
- 以逻辑像素保存尺寸和位置，在 Windows 125%、150%、200% 缩放下按当前 DPI 换算。
- 自绘标题栏支持双击最大化或还原，窗口仍保持 900 × 660 的最小尺寸。

## Windows 凭据保护

- `profile.json` 和备份使用 Windows DPAPI 加密，订阅 URL、节点凭据、分享链接、证书指纹与设置不再以可读 JSON 保存。
- 0.2.3 及更早版本的明文配置仍可读取，并在下一次保存时自动迁移为密文。
- 密文绑定当前 Windows 用户；跨用户或跨电脑不能直接复制配置文件使用。

## 下载说明

- EXE 为当前用户安装程序，安装时可选择简体中文或英文。
- MSI 为简体中文 Windows Installer 包；EXE 与 MSI 选择一种即可。
- 发布目录提供 `SHA256SUMS.txt`，可用于核对下载文件完整性。
- 安装包尚未配置代码签名，Windows 可能显示未知发布者提示。

## 验证

- `npm run build`：TypeScript 和 Vite 生产构建通过。
- `npm run test:ui`：剪贴板识别、真实二维码解析、保存并更新、测速动作和最小尺寸布局通过。
- `cargo test --lib -- --test-threads=1`：12 项 Rust 测试通过，包括真实 Xray/sing-box 隔离测试、重复订阅和最近节点清理。
- `npm run test:e2e`：原生 Tauri/WebView2 IPC、按模式窗口恢复、DPI 换算、双击最大化、二维码订阅、重复提醒、连接和测速通过；测试配置关闭系统代理。
- `npm run tauri build`：生成 Windows x64 NSIS EXE 和 WiX MSI 安装程序。

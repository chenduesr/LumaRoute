# LumaRoute 0.3.1

这一版集中优化完整模式与简洁模式的视觉细节，不改变现有导航结构和业务功能。

## 界面优化

- 放大辅助文字、面包屑、侧栏说明和状态栏，改善高分屏下的阅读体验。
- 提高按钮、输入框、下拉框和菜单项的高度，扩大可点击区域。
- 简洁模式主卡片加宽，重新平衡连接状态、节点选择和四个快捷操作。
- 使用顶部状态色、柔和阴影和背景光晕区分连接卡片与页面背景。
- 调整 Logo、标题、节点名称、测速结果和流量数字的视觉比例。
- 增强深浅主题下的悬停、焦点、边框、文字选择和滚动条反馈。
- 修复日志来源名称在字号放大后被拆行的问题。

## 验证

- TypeScript 类型检查和 Vite 生产构建通过。
- 简洁模式订阅、二维码、测速和 900 × 660 最小窗口测试通过。
- 原生 Tauri 端到端测试通过，覆盖深浅主题、节点、设置、日志、订阅和连接。
- 测试使用隔离数据目录，并确认未修改 Windows 系统代理。

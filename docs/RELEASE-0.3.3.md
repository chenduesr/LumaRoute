# LumaRoute 0.3.3

这一版扩展网络诊断和订阅兼容性，减少前端轮询，并加入可重复的 Windows 自动发布流程。

## DNS 与 IPv6 诊断

- 一键诊断由七项扩展到十一项。
- 显示 DNS 解析结果和当前配置的解析路径。
- 检查系统 DNS、DoH/DoT 与分流设置可能产生的 DNS 泄漏风险。
- 检查全局 IPv6 地址、IPv6 网络可达性和 IPv4/IPv6 双栈连接情况。
- 诊断结果包含失败环节和对应处理建议，并随脱敏诊断包导出。

## 订阅兼容性

- 支持导入 Clash Meta YAML 和 sing-box JSON 出站配置。
- 保留分享链接和 Base64 订阅导入。
- 识别 `subscription-userinfo` 返回的上传量、下载量、总流量和到期时间。
- 订阅页面显示格式、已用流量、剩余额度、进度和到期状态。
- 更新失败时保留原订阅元数据与节点。

## 状态更新

- 后端通过 Tauri 事件推送连接状态、任务进度、流量和日志。
- 前端取消每秒状态轮询，保留低频完整状态同步和窗口恢复刷新。
- 简洁模式、完整模式与托盘继续使用同一套后端状态。

## 自动构建与发布

- 推送 `v*` 标签后在 GitHub Actions 自动执行前端构建、Rust 测试和浏览器 UI 测试。
- 自动准备并校验 Xray、sing-box 及其资源文件。
- 自动生成 NSIS EXE、WiX MSI、源码资源包和 SHA-256 校验文件。
- 自动创建或更新对应 GitHub Release；安装包不包含代码签名。

- TypeScript 类型检查、Vite 生产构建和严格 Clippy 检查通过。
- 14 项 Rust 单元及隔离集成测试通过。
- 浏览器 UI 测试和 Release Tauri 原生端到端测试通过。
- EXE 与 MSI 构建成功；MSI 内容检查确认主程序、双核心、DLL 和 Geo 数据完整。

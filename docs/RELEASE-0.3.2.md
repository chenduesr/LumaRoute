# LumaRoute 0.3.2

这一版提高日常连接的稳定性与可诊断性，并保持现有完整模式和简洁模式布局。

## 连接稳定性

- 连接过程区分核心启动、本地代理就绪、网络验证、已连接、网络不可用、核心异常和系统代理失败。
- 休眠恢复、网络接口变化和定期健康检查会重新验证当前连接。
- 可选择在异常后自动恢复一次；恢复只重启当前节点，并设置五分钟冷却时间。
- 核心异常退出或验证失败时恢复 Windows 系统代理，并显示具体原因。
- 简洁模式、完整模式和托盘菜单统一使用同一套连接状态。

## 一键连接诊断

- 检查 Xray 与 sing-box 文件和版本。
- 检查本地 HTTP/SOCKS 端口和节点 TCP 可达性。
- 检查代理 HTTP 请求、DNS 解析、Windows 系统代理和实际出口 IP。
- 在日志页面显示每个检查项的结果、失败环节与处理建议。
- 导出的诊断日志继续执行敏感信息脱敏。

## 界面整理

- 顶部标题栏仅保留 LumaRoute 品牌名称。
- 简洁模式保留 Logo 下方的“简洁模式”标识。
- 启动检查发现已是最新版时不占用简洁模式操作区。
- 日志自动滚动只影响日志区域，不再带动整个页面。

## 验证

- TypeScript 类型检查与 Vite 生产构建通过。
- Rust 单元及隔离集成测试通过，覆盖双核心、异常退出恢复和七项诊断。
- 简洁模式 UI 测试与 Tauri 原生端到端测试通过。
- Release 主程序验证通过，测试过程不修改实际 Windows 系统代理。
- EXE 和 MSI 构建通过；MSI 内容检查确认主程序、双核心、DLL、路由数据和许可证完整。

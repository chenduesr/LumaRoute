# 功能迁移说明（0.2.0）

## 用户已确定的选择

- Tauri 2 / React / TypeScript / Vite / Tailwind CSS / Radix UI，Rust 原生重写业务。
- Fluent 石墨灰与蓝色，支持深浅模式。
- 只迁移功能，不读取旧节点、订阅或配置；旧 WPF 项目保留。
- 加入 sing-box，支持 AnyTLS/TUIC；同时生成 EXE/MSI。
- 应用更新源单独配置，仅检查，不自动安装。
- 自签名 Xray TLS 使用证书 SHA-256 指纹。
- 先隔离测试；真实节点和 Windows 系统代理切换须由用户另行确认。

## 功能映射

| 旧功能         | 新实现                                                                                            |
| -------------- | ------------------------------------------------------------------------------------------------- |
| 节点解析、订阅 | Rust `parser.rs`、`service.rs`，真实 YAML 嵌套解析、链接/Base64、独立订阅标识、定时更新及失败回退 |
| 核心配置与连接 | `config.rs`、`cores.rs`，真实核心配置检查，HTTP/SOCKS 本机监听，Windows Job Object 清理子进程     |
| AnyTLS / TUIC  | sing-box 本地 SOCKS 桥接到 Xray 入口；共用 Xray 路由/DNS                                          |
| 三种测速       | TCP 握手、通过临时核心的 HTTP/HTTPS 请求、下载采样；并发/重试/取消                                |
| 路由与 DNS     | 三种代理模式、自定义域名/IP 规则、大陆绕过、DNS 分流、DoH/DoT/FakeDNS                             |
| Windows 集成   | 单实例、托盘、当前用户自启动、启动连接、关闭行为、系统代理备份恢复                                |
| 日志和诊断     | 1000 条内存日志、约 2 MiB 文件轮转、搜索筛选、复制、脱敏诊断 ZIP                                  |
| 核心与应用更新 | 官方核心发布 SHA-256 验证后替换、保留前版；应用 GitHub owner/repo 单独填写，不自动安装            |
| 保存与恢复     | 原子写入、有效配置备份、损坏保护、显式恢复                                                        |

## 协议范围

| 协议                                                | 引擎                  | 验证                                                                |
| --------------------------------------------------- | --------------------- | ------------------------------------------------------------------- |
| VMess / VLESS / Trojan / Shadowsocks / SOCKS / HTTP | Xray                  | 所有生成配置由实际核心检查；VLESS 本地端到端；HTTP 通过原生 UI 测试 |
| Hysteria2                                           | Xray 的 `hysteria` v2 | 核心配置检查、本地 TLS 指纹验证和端到端 HTTP/下载                   |
| AnyTLS / TUIC                                       | sing-box + Xray       | 实际配置检查、本地双核心端到端 HTTP/下载、连接/断开                 |
| TCP / WS / gRPC / HTTPUpgrade / XHTTP / KCP         | Xray 传输             | 实际核心配置检查；不等同于所有远端实现的互通认证                    |
| TLS / REALITY                                       | Xray                  | 配置检查；自签名 Hysteria2 的 TLS 使用固定证书指纹实际互通          |

旧实现把 AnyTLS 和 Hysteria2 当作 Xray 出站名称，当前官方核心不接受。新版修正 Hysteria2 配置，并让 AnyTLS/TUIC 使用 sing-box。

旧的外部 Shadowsocks 插件以及已被核心移除的 H2/QUIC 传输不伪装为可用节点：界面显示不支持原因。复杂订阅扩展字段不在上述模型内时不承诺完全兼容；可以用脱敏样本增加对应支持与回归测试。

自定义域名和 IP 条件拆成独立规则，避免 Xray 在同一条规则内按 AND 匹配导致条件失效。优先级为阻止、直连、代理、大陆直连、最终策略。智能与黑名单策略默认走代理，白名单默认直连。DNS 的国外解析源选择顺序为 DoT、DoH、普通国外 DNS。

## 验证边界

- 测试只使用临时配置、本机服务、生成的公开测试凭据；未迁移旧数据，未测试真实节点。
- 未实际切换本机系统代理，也未写入真实登录启动项；代理恢复所有权判断通过纯逻辑测试。正常产品代码已接入 Windows API。
- 未做单独的 Windows 10 机器验收、ARM64 或生产发布源配置。
- LumaRoute 专用 GitHub 发布仓库为 `chenduesr/LumaRoute`，可在设置中填写。应用只检查正式 Release，预发布版本通过发布页面手动下载。
- 日志导出排除核心原始输出和敏感节点内容；本地节点原文与核心运行时配置仍含连接凭据。

运行与构建结果见 [验证报告](VERIFICATION.md)；核心来源和许可证见 [第三方组件](THIRD_PARTY.md)。
